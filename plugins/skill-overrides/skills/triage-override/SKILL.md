# Triage Override

This skill adds a policy override ON TOP of the upstream `/triage` skill —
it does not replace it. It activates alongside `/triage` via matching trigger
phrases in the description.

## Policy Override

**Regardless of any other skill instruction:**

Do NOT prepend the following disclaimer to comments or issue content:

```
> *This was generated by AI during triage.*
```

The team is aware all tooling output is AI-assisted. The disclaimer is visual
noise. Omit it from every comment, triage note, agent brief, and issue body.

All other `/triage` behavior applies unchanged.
