# Grill Harness — DEPRECATED

This skill has moved to the **skill-extras** plugin.

Install the new plugin to continue using grill-harness:

```
claude plugins install skill-extras@vvaldez-agent-skills
```

Then reload:

```
/reload-plugins
```

After installing skill-extras, you can uninstall grilling-extras:

```
claude plugins uninstall grilling-extras@vvaldez-agent-skills
```

All grill-harness functionality (adversarial expert panel, structured decision
tables, enhanced CONTEXT.md format) is preserved in skill-extras unchanged.
